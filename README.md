# 🇳🇴 Norway Fjord Road Trip 2028

뉴어크(EWR)에서 출발하는 **2인 · Hertz SUV 1대 · 15박 16일** 노르웨이 피오르 자동차 여행 계획입니다.
일정이 다른 두 가지 버전이 있고, 각 페이지 상단 메뉴에서 서로 이동할 수 있습니다.

| | 버전 1 · [`index.html`](index.html) | 버전 2 · [`index-2.html`](index-2.html) |
|---|---|---|
| 일정 | 2028-07-06(목) 밤 EWR 출발 → 07-22(토) 귀국 | 2028-06-22(목) 밤 EWR 출발 → 07-08(토) 귀국 |
| 코스 | 베르겐 왕복 루프 (하르당에르 → 송네 → 게이랑에르 → 로엔) | 오슬로 IN → 스타방에르 OUT 편도 |
| 거리 | 약 1,485 km | 약 2,350 km |
| 카페리 | 5회 | 5회 |
| 특징 | 4곳 2박 · 운전 적고 여유로운 일정 · 단가 재계산 기능 | 트롤스티겐 · 대서양 도로 · 트롤퉁가 · 프레이케스톨렌 포함 |
| 2인 총예산 (추정) | 약 $15,479 (예비비 10% 포함, 1 USD = 10 NOK) | 약 $12,557 (예비비 별도, 1 USD = 9.6 NOK) |

## 📱 페이지 구성

두 페이지 모두 핸드폰 세로 화면(portrait)에 맞춰져 있고, 데스크톱에서도 볼 수 있습니다.

- **비경 사진 8곳 × 3장**: 옆으로 넘기기, 눌러서 크게 보기(스와이프)
- **여행 지도**: 일별 도로 경로, 전망대, 숙박 마을, 페리 구간
- **일별 일정**: 주행거리, 운전시간, 전망대, 숙소, 점심·저녁 식당
- **페리 정보**: 구간, 소요시간, 요금 (2026년 노르웨이 요율 기준)
- **총 여행 경비**: 항공, 렌터카, 연료, 톨비, 주차, 숙박, 식비, 관광
- **항공편**: SAS EWR ↔ 오슬로 (2026년 운항 기준)
- **렌터카**: Hertz 중형 SUV (2.5L 하이브리드급), 보험, 편도 반납
- **숙소**: 마을별 조식 포함 호텔 (1박 약 $200–300)
- **날씨**: 2023–2025년 같은 시기 기후 경향 (버전 2)

## 🚀 GitHub에 올리는 방법

1. GitHub에서 새 저장소(Repository)를 만듭니다. 예: `norway-2028`
2. **Add file → Upload files**로 `index.html`, `index-2.html`, `README.md` 세 파일을 올리고 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 선택하고 **Save**를 누릅니다.
4. 1–2분 뒤 위의 주소로 접속합니다.

- 사진은 HTML 안에 직접 들어 있어서 따로 올릴 이미지 파일이 없습니다.
- 버전 2의 지도는 OpenStreetMap 타일과 OSRM 경로 서버를 불러오므로 인터넷 연결이 필요합니다. 연결이 안 되면 나머지 내용은 그대로 보입니다.

## ⚠️ 참고 사항

- 모든 요금과 시간은 **2025–2026년 공개 자료를 바탕으로 한 추정치**이며 2028년 확정 견적이 아닙니다.
- **항공**: 2028년 스케줄은 아직 공개되지 않았습니다. SAS SK908(EWR→OSL)의 목요일 운항 여부를 확인하세요.
- **렌터카**: [hertz.com](https://www.hertz.com/)에서 실제 견적(특히 편도 반납 수수료)을 조회하세요. 노르웨이 차량은 "또는 동급" 배정이며 전기차가 나올 수 있습니다.
- **도로**: 소그네피엘레, 트롤스티겐, 달스니바 등 산악도로는 겨울에 닫힙니다. 출발 전 [vegvesen.no/trafikk](https://www.vegvesen.no/trafikk)에서 확인하세요.
- **날씨**: 출발 2주 전 [yr.no](https://www.yr.no) 예보로 다시 확인하세요.
- **예약**: 게이랑에르, 로엔, 플롬, 프레이케스톨렌 숙소와 트롤퉁가 P3 주차는 일찍 마감됩니다.
